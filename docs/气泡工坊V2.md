# 气泡工坊 V2:主题引擎、模板与 AI 生成

气泡外观从"22 个扁平字段 + 一个圆角 shape"升级为**主题引擎驱动的 V2 模型**:
模板(骨架)× 材质(表面)× 配色(派生 + 覆盖)× 版式。编辑器、AI 生成、预览与真实舞台
共用同一套 `src/bubble` 引擎与同一条渲染链路——工坊所见即舞台所得。

```text
旧 V1 主题 ──┐
手工编辑 ────┼→ src/bubble 引擎 ─→ resolveBubbleAppearance ─┬→ 舞台真实气泡(Bubble.tsx)
AI 设计意图 ─┘        │                                     └→ 工坊预览(BubbleSettings)
                      ├→ 兼容性修正(模板×材质白名单)
                      ├→ 配色派生(primary → 12 语义色)
                      ├→ 对比度诊断 + autoFix(带修复说明)
                      └→ mutateBubbleTheme(统一改稿动作)
```

## 一、公共接口(刻意收窄)

外部只经 `src/bubble/index.ts` 使用引擎:

| 接口 | 用途 |
|---|---|
| `normalizeBubbleTheme` / `normalizeBubbleThemeAny` | V2 清洗;V2+V1 混合归一化(V1 就地迁移),幂等 |
| `resolveBubbleAppearance(theme, options)` | 主题+减弱动效选项 → 结构属性 + `--bub-*` 变量 + 每角色取色 |
| `listBubbleTemplates()` | 模板画廊/材质下拉的数据源(含兼容材质白名单) |
| `mutateBubbleTheme(theme, action)` | 统一改稿:换模板(preserve 组)、换材质、快捷动作 |
| `generateBubbleCandidates(requirement)` | AI 三候选(槽位制),内部经 compileIntent+autoFix |
| `diagnoseBubbleTheme` / `autoFixBubbleTheme` / `effectiveBubbleColors` | 诊断、修复(返回 fixes 说明)、12 语义色终值 |
| `BUILT_IN_BUBBLE_THEMES` / `isBuiltinBubbleThemeId` | 内置柔彩(comic)/夜色玻璃(glass),不可变 V2 |
| `BubbleThemeProvider` / `useBubbleTheme` / `Bubble` | React 侧:主题下发 + 气泡视图组件 |
| `syncBubbleCompatVars(root, theme)` | 根节点唯一职责:同步 `--bubble-acc-a/b/c` 兼容变量 |

颜色数学(hex↔HSL、混合、对比度)是模块私有实现,不对外暴露。

## 二、主题作用域(关键设计)

主题**不落在根节点**。`Bubble` 组件从 Provider 取当前 V2 主题,在自身节点上 resolve,
把 `data-template / data-material / data-nameplate / data-tail` 属性和 `--bub-*` 变量
**直接写到 `.bubble-shell` 上**;CSS 全部是 `.bubble-shell[data-template='x']` 自反选择器。
工坊三候选嵌套预览因此天然隔离,不与全局主题串色。

根节点只保留一个兼容 adapter(`syncBubbleCompatVars`):同步 `--bubble-acc-a/b/c`,
供两处旧消费者使用——群聊说话人名(App.css `.chatlog-row.spk-*`)与群聊头像
(ChatLogSettings `avatarAccent`)。

`:root` 上的静态 `--bub-*` 变量是启动首帧兜底(值=柔彩 V2 的 resolve 输出),
主题加载前不裸奔;旧 `:root[data-bubble='glass']` 分支已删除。

## 三、V2 数据模型

```ts
interface BubbleThemeV2 {
  version: 2
  id: string            // custom_ 前缀(自定义)或内置 comic/glass
  label: string         // ≤10 字
  templateId: 'soft-chat' | 'pill' | 'comic-burst' | 'cloud' | 'sticker' | 'rpg' | 'caption'
  material: { id: 'solid'|'gradient'|'glass'|'paper'|'neon'; opacity: 0.35~1; blur: 0~24 }
  palette: {
    mode: 'unified' | 'per-speaker'
    primary: string          // 主色(派生出发点)
    lightness: 'light'|'dark'
    speakerStrength: 0~100   // 角色区分强度
    overrides?: { surface? text? outline? accA-C? surfaceA-C? outlineA-C? }  // 12 语义色可选覆盖
  }
  frame: { radius: 6~28; outlineWidth: 0~4 }
  typography: { fontPreset: 'friendly'|'comic'|'clean'|'pixel'; size; weight; lineHeight; align }
  nameplate: { style: 'badge'|'tab'|'inline'|'hidden'; position: 'top-left'|'top-center'|'inside' }
  tail: { style: 'droplet'|'triangle'|'curve'|'bubbles'|'none'; size: 10~24 }
  layout: { maxWidth: 240~520; paddingX: 10~28; paddingY: 8~28 }
  effects: { shadow: 'none'|'soft'|'strong'; glow: 0~100; texture: 0~100 }
}
```

要点:
- `fontPreset` 四档均映射系统字体栈;pixel 优先使用本机 Fusion Pixel/Zpix,缺失时回落宋体等宽栈。
- 简洁配色模式 = 只写派生输入(primary/lightness/speakerStrength/mode),引擎重算全套;
  高级模式 = 写 `overrides` 单独覆盖某语义色,其余仍派生。简洁控件改动会清 overrides。
- 材质不在模板白名单时 normalize/resolve 双重回落 defaultMaterial;blur 非 glass 强制 0。

## 四、七模板 × 材质兼容矩阵

| 模板 | 骨架 | 兼容材质 | 默认材质 |
|---|---|---|---|
| soft-chat 柔和对话 | 圆角框+水滴尾 | 全部 5 种 | gradient |
| pill 胶囊 | 999px 胶囊+弧尾 | solid/gradient/glass/neon | solid |
| comic-burst 漫画爆发 | 双层同形锯齿+drop-shadow | solid/neon | solid |
| cloud 云朵 | frame 背景层圆瓣+圆泡串尾 | solid/gradient/glass | gradient |
| sticker 手账贴纸 | 8 值不规则圆角+歪斜+胶带 | solid/gradient/paper | paper |
| rpg 文本框 | 方角双线+tab 标签槽 | solid/glass/paper/neon | solid |
| caption 极简字幕 | 半透明横条+行内名签、无尾 | solid/glass/neon | glass |

视觉实现注意(踩过的坑):
- 漫画爆发框的锯齿描边必须**内外两层同形 polygon**(外层 `inset:-w` + edge 色),
  阴影走 `filter: drop-shadow()`——box-shadow 会按矩形盒绘制,clip-path 也裁不到它;
  文字层不参与裁剪,名签/情绪符移进锯齿内部。
- 云朵用 **SVG data-URI mask**(中央椭圆+外圈瓣的并集,`mask: center / 100% 100%`)
  分别裁剪描边层与底色/材质层:radial-gradient 做不出这个形状(椭圆百分比 size 本就
  不合法,Chrome 会按 farthest-corner 铺成矩形);正文层不 mask,多行不失真、名签不裁;
  材质 `--bub-surface-image` 叠在形状内部,玻璃的 backdrop-filter 也迁到形状层
  (shell 无底色,blur 留在 shell 上对玻璃组合不生效)。
- 玻璃材质:`contain: layout style`(**不含 paint**——名签/尾巴在盒外,paint 会裁掉它们);
  模糊上限 24px;backdrop-filter 失效时 `@supports` 天然回落半透明纯色。
  Tauri 实机需核验 WebM 视频同屏时的合成表现。
- 阴影/辉光语义:`effects.shadow='none'` 就真的无投影(漫画也不落 drop-shadow);
  辉光独立于阴影档位,任何档位(含无阴影)都以纯光晕形式生效。

## 五、CSS 变量清单(`--bub-*`,resolve 产出)

颜色:`--bub-text`、`--bub-surface(-a/b/c)`、`--bub-edge(-a/b/c)`、`--bub-acc-a/b/c`、
`--bub-shadow-c(-a/b/c)`。版式:`--bub-font/-font-size/-font-weight/-line-height/-align`、
`--bub-max-w/-pad-x/-pad-y`。框架:`--bub-radius`(pill 时=999px)、`--bub-outline-w`。
表面:`--bub-surface-image`(渐变高光/纸噪点)、`--bub-backdrop`(玻璃模糊)。
效果:`--bub-shadow`(sticker 为硬偏移阴影)、`--bub-filter`(漫画 drop-shadow)、
`--bub-in`(入场动画,reducedMotion 时 none)。转译层(shell 内)按 `data-speaker`
把 `-a/b/c` 组落到生效值;`--sp`(名签/情绪/辉光色)与 `--bub-glow-color` 由 CSS 定义。

## 六、DOM 结构

```tsx
<div className="bubble-shell" data-template data-material data-nameplate
     data-nameplate-pos data-tail data-tail-side data-speaker data-mood style={cssVars}>
  <div className="bubble-frame">
    <span className="b-name"><i/>{name}</span>   <!-- badge/tab 时;hidden 不渲染(aria-label 保留说话人) -->
    <span className="b-text">{inline 名签时前缀 .b-who}{text}</span>
    <span className="b-mem">🧠 …</span>
  </div>
  <span className="bubble-tail" aria-hidden />   <!-- 五尾型,独立节点 -->
  <span className="bubble-deco" aria-hidden />   <!-- 情绪符(::after)+ 模板装饰(sticker 胶带 ::before) -->
</div>
```

below/loud/long/out 仍是类名;`data-tail-side`(left/center/right)驱动尾巴横向偏移。

## 七、V1 → V2 迁移(读取时,颜色零丢失)

| V1 | V2 |
|---|---|
| shape rounded/pill/square/cloud | soft-chat / pill / rpg / cloud |
| tailStyle droplet/sharp/round/none | droplet / triangle / curve / none |
| blurPx>0 | material=glass(模板不兼容则 solid),blur 保留 |
| bg/text/stroke、accA-C、bgA-C、strokeA-C | palette.overrides 12 色**全量写入** |
| bgOpacity/strokeW/fontSize/maxWidth/radius/fontWeight/lineHeight/paddingX/Y | material.opacity/frame.outlineWidth/typography/layout 逐项继承 |
| — | primary=accA;lightness 按文字亮度判定;三角色底色相同判 unified |

迁移只在读取时发生,保存后写 `version: 2`;normalize 幂等。存储文件
`appData/data/bubble-themes.json` 恒为 `{ version: 2, themes: [...] }`,
V1/V2 混合旧文件可读。旧 `BubbleTheme`/`useBubbleThemes` 投影视图已经删除;
舞台、工坊与 GeneralSettings 全部直接读取 V2,内置主题 label 也来自同一个目录。

## 八、AI 生成:设计意图 + 三槽位

LLM 不再自由生成几十个 CSS 参数,只输出 `BubbleDesignIntent`
(slot/label/templateId/materialId/mood/lightness/primaryColor/typographyPreset/nameplateStyle)。
三槽位强制方向差异:**faithful**(贴描述)、**expressive**(强轮廓/材质,如漫画+霓虹)、
**restrained**(克制长显,如字幕/RPG)。程序只做:模板×材质兼容降级(defaultMaterial)、
编译(骨架/版式取模板默认,配色派生)、autoFix(返回修复说明),并两两校验
`templateId/materialId/primaryColor` 至少两项不同;不足时从确定性方向池轮换补位。
槽位缺失或输出非法时用**同 mood 内置变体补位**,绝不随机改写合法候选的模板。

工坊 UI:三候选并排 mini 预览 →「用这个」进编辑器;编辑器附快捷改稿钮
(名签更简/阴影弱一点/字体更活泼/随机微调/恢复模板默认),全部经 `mutateBubbleTheme`。

## 九、例外与边界

- **C 画外音横幅**(`.guest-bubble`,C 禁用立绘时):固定采用 caption 语义
  (低干扰半透明条),取色经 `resolveGuestLook` 来自当前主题。
- **用户输入回显**(`.user-bubble`)不纳入气泡工坊(它是"你说的",不是角色演出)。
- 预览场景矩阵:短句/长文本/喊话 × 角色上方/下方 × 浅色/深色/透明桌面,
  外加"保存前后对比"开关;预览与舞台复用同一 `Bubble` 组件。

## 十、验收标准核对

- 七模板去色可辨:模板画廊缩略图与舞台骨架同构(CSS 同源)。
- 编辑项预览=舞台:同一组件、同一 resolve、同一 CSS。
- 旧主题升级保色:12 色全量进 overrides,行为测试覆盖。
- 长文本/喊话/翻转:`.long`(降 2px 字号)、`.loud`(加大加粗)、`.below`(尾巴朝上)不溢出。
- AI 三候选方向互异;无效组合自动降级;危险配色有诊断+一键修复(带说明)。
- 内置可复制、自定义可恢复模板默认;切换主题无残留(shell 属性+变量随节点重建)。

## 十一、新增一个模板的四处必改

1. `src/bubble/types.ts`:`BUBBLE_TEMPLATE_IDS` 加 id。
2. `src/bubble/catalog.ts`:`BUBBLE_TEMPLATES` 加条目(兼容材质、默认材质、defaults)。
3. `src/App.css` 模板骨架段:`.bubble-shell[data-template='…']` 规则(骨架只写结构,
   颜色一律消费 `--bub-*`)。必要时 `resolve.ts` 补该模板的阴影/圆角特化。
4. 测试:`tests/bubbleEngine.test.mjs` 的目录完整性用例会自动覆盖新模板的
   "材质白名单含默认材质"与"全部兼容组合 resolve 合法"两条。

## 十二、排查表

| 症状 | 先查 |
|---|---|
| 气泡回到默认柔彩 | `config.bubbleStyle` 指向的主题被删(回退逻辑),或 store 加载失败 |
| 切主题有残影/串色 | 是否有代码绕过 Provider 直接写根节点变量;`syncBubbleCompatVars` 是否被跳过 |
| 名签/尾巴被裁 | 模板规则是否给 shell/frame 加了 `contain: paint` 或对文字层做了 clip-path |
| 漫画框没有描边 | `.bubble-frame::before` 的 inset 与 `--bub-outline-w`;outlineWidth=0 时无描边属正常 |
| 玻璃无模糊 | `--bub-backdrop`;WebView 是否支持 backdrop-filter(否则半透明纯色回退) |
| 群聊说话人名/头像颜色不动 | 根节点 `--bubble-acc-a/b/c`(adapter 同步),或 overrides 里的 accA-C |

# 气泡水平防出屏设计方案

> 审计结论:气泡纵向有贴顶防护(头部 110px 内 `below` 翻转),横向无——
> `.bubble-shell` 在 `.actor` 容器内恒为 `left:50% + translateX(-50%)` 对中角色,
> `data-tail-side` 只挪尾巴锚点(`--bub-tail-x` 42%/58%)不搬主体。角色被拖到
> 屏幕左右边缘、或 C 团宠漫游到边时,气泡主体被透明窗裁切。对方项目
> (Re-Dreaming)的"头顶→右侧→左侧→clamp 回屏"四级放置,缺横向等价物。

## 方案

**主体恒对中不动摇,贴边时整体平移拉回屏内。** 对方式的"把主体翻到角色另一侧"
不需要:我们的气泡默认悬在角色上方,与立绘不重叠,平移已彻底消除裁切;换边反而
引入"气泡与邻位角色/道具重叠"的新问题。

放置决策从纯 CSS 加一层 JS 测量(纯函数 + 组件接线两层):

1. **纯函数 `bubbleShiftX(bubbleLeft, bubbleWidth, viewportW, pad)`**
   (src/bubble/position.ts):输入气泡当前自然左缘与宽度,返回应加的水平位移:
   - 已在 `[pad, viewportW-pad]` 内 → 0;
   - 左溢出 → 右移到左缘 = pad;右溢出 → 左移到右缘 = viewportW-pad;
   - 双侧都放不下(屏窄于气泡)→ 取正中(两侧均分溢出,极端场景不至于全被裁掉);
   - 退化输入(宽 0 / 视口 0)→ 0。
2. **组件接线**(src/bubble/view.tsx,Bubble 是舞台 A/B/C 与工坊预览共用实现,
   一处修复三处受益):`useLayoutEffect` 里测 `getBoundingClientRect()`,
   用 ref 镜像反解自然位置(已应用的位移不参与计算,避免二次叠加),结果落
   `marginLeft` 位移(`position:relative` 流内元素,不与任何入场/退场 transform
   动画打架);依赖 `[shown, below, loud]` 重测(文本变化即宽度变化)+
   `resize` 监听。位移取整,|dx|<0.5 归零防抖动。

## 明确不做

- **不搬尾巴**:位移后尾巴不再精确指向头顶,是可接受的视觉近似;尾巴跟随位移
  需要 shell→tail 的二级换算,收益不抵复杂度。
- **不做纵向 JS 测量**:`below` 翻转已覆盖贴顶;贴底时气泡默认朝上,无裁切面。
- **不改工坊预览定位**:预览窗口内同样适用(视口即预览窗),行为一致。

说话同验;居中场景位移恒 0(与现状无差异)。

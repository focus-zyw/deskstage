# 角色立绘规范

本文档是角色形象图的完整制作规范,可直接照做,也可作为约稿交接材料发给画师。

> 规格来源:`scripts/gen_placeholder_sprites.py` 文件头注释(权威定义)与 `src/stage/spriteSets.ts` 头注释。
> 素材现状:**A/B 两角色均为用户自生成形态**(A 便利店少女、B 程序员),原始图在本地 `temp/{girl,boy}-*.png`(temp/ 不入库),经 `scripts/process_user_sprites.py {girl|boy}` 规格化输出(alpha 阈值取边界 → 以 idle 高为基准统一缩放 → 底边对齐居中)。换新素材时同名覆盖即可,代码零改动。B 角色另有 `shy.png`(害羞,连戳反应用),A 无此图、运行时回退 idle。

---

## 一、技术规格(硬性要求)

### 1.1 文件清单

每个角色 6 张 PNG,两个角色共 12 张:

| 文件名 | 用途 | 程序中的动画 |
|---|---|---|
| `idle.png` | 默认站立 | 呼吸(上下 ±3px,4s 循环) |
| `talk.png` | 说话(张嘴态) | 点头(上下 ±6px,0.6s 循环) |
| `happy.png` | 开心 | 同 idle 呼吸 |
| `angry.png` | 生气 | 同 idle 呼吸 |
| `sad.png` | 沮丧 | 同 idle 呼吸 |
| `surprise.png` | 惊讶 | 同 idle 呼吸 |

- 文件名全小写,与动作词严格一致,放在 `public/sprites/a/`(角色甲)和 `public/sprites/b/`(角色乙)。
- `shake`(摇头)和 `jump`(跳跃)**不需要出图**,程序自动复用 `idle.png` 加 CSS 位移动画。
- 乙可选加第 7 张 `shy.png`(害羞):连戳时的害羞反应用;甲没有此图也不会报错,程序自动回退 `idle.png`。
- 被点击时的挤压弹跳(boing)和悬停发光由 CSS 处理,不影响画图。
- 工具任务可选增加 `reading.png`(阅读文档)与 `present.png`(展示结果):两者只由
  OCR/翻译/提醒等本地流程触发,不会开放给 LLM 的普通对话动作协议。
- 同一动作可增加姿势变体(如 `talk-point.png`),并在 `spriteSets.ts` 的
  `variants` 中配置权重、冷却和切图方式。变体不新增 LLM 动作词,只在进入原动作时偶尔替换基础图。
- 手臂/道具轮廓变化大的变体应使用 `transitionMode: 'dip'`,让旧图先退再进,避免交叉淡入时短暂出现多只手。

### 1.2 画布与格式

| 项目 | 要求 |
|---|---|
| 画布尺寸 | **440 × 640**(宽 × 高) |
| 格式 | PNG,**RGBA 透明背景**(不许有白底/纯色底) |
| 显示尺寸 | 高度锁定 320 逻辑像素,宽度按图片比例自适应 |

440×640 正好是显示高度的 2 倍,适配 Windows 125% / 150% DPI 缩放。若宽高比偏离 440:640,程序不会报错(高度锁 320、宽度自适应),但会偏离整体布局,请遵守规格。

### 1.3 构图与对齐

- **全身单人**,身体左右居中。
- **脚底贴画布底边**(y=640),不要悬空、不要留脚底空隙。
- 角色要**撑满画布高度**:头顶留 10~20px 即可,不要让角色只占下半张,否则显示出来会显得矮小。
- **同一角色的 6 张图头脚位置严格对齐**——这是最重要的一条。动作切换是整图交叉淡入(0.14s):身体对齐时,切换看起来只是"脸变了";身体错位会明显穿帮。
- **不要画影子**:角色在程序里是底边对齐窗口的,图里带影子会显得悬空。

### 1.4 与代码的关系

- **没有精灵表、没有序列帧、没有分层**。每个动作就是一整张静态图,动画节奏全部由 CSS 位移动画承担;**服装必须画进整图**(换装 = 整张替换)。
- 替换素材:同名覆盖 `public/sprites/{a|b}/` 下的 PNG,重启应用 / 刷新页面生效。
- 角色名字与主色在 `src/stage/spriteSets.ts` 的 `SPRITE_SETS` 里:甲 `name: '甲'`、主色蓝 `#3d8bd4`(便利店店员);乙 `name: '乙'`、主色灰蓝 `#5a6472`(程序员)。主色只影响名牌颜色和缺图兜底胶囊。改名/换主色需改这个文件;素材留白造成的小幅偏移可用其 `offsetX/offsetY` 微调。
- 图片加载失败时程序会回退为纯 CSS 胶囊小人,演出不中断,但请以素材正常加载为准。

## 二、形象设计原则

适用场景:**铺满主显示器的全屏透明穿透覆盖层**(桌面即舞台,未命中角色/控件处鼠标事件全部穿透给下层应用),两个角色站在屏幕左右两侧(默认左 20vw / 右 20vw)、320px 高起(滚轮可缩放 140px~屏幕高)、带名牌和对话气泡,表演相声/闲聊。

### 2.1 头身比:2~2.5 头身 Q 版

320px 显示高度下,写实 7 头身人物的脸只有几十像素,表情完全看不清。大头 Q 版的眉眼嘴缩放后依然可读,也是桌宠的主流调性。建议 **2~2.5 头身**,最多不超过 4 头身。

### 2.2 搭档成对设计,一眼区分

相声是逗哏 + 捧哏的对比关系,两个角色按"搭档"成对设计:

- 体型一高一矮 / 一圆一瘦,性格一活泼一冷面;
- 配色一冷一暖,对比要强;
- 现有主色可直接沿用:甲蓝 `#3d8bd4`、乙灰蓝 `#5a6472`(若另定主色,画完后同步改 `spriteSets.ts` 的 `accent`,保持名牌配色协调)。

### 2.3 剪影简洁、大色块、粗轮廓

- 细碎花纹、复杂渐变、精细线稿缩到 320px 全会糊,用**扁平大色块 + 粗描边**最耐缩放;
- 外轮廓要有辨识度(发型、体型、道具);
- 可加相声元素当记忆点:长衫、折扇、醒木、瓜皮帽等。

### 2.4 表情差异集中在脸,身体保持不动

正确做法:**画一张定稿的身体,复制 5 份,只改眉/眼/嘴**,姿态最多微调(手的位置、头微倾)。身体大幅移动会破坏头脚对齐。

### 2.5 姿势要"经得起被动画驱动"

程序会对图做上下呼吸、点头、左右摇晃(±4px)、跳起(26px)、挤压弹跳,所以:

- 画**正面或微侧的站立姿**,双脚落地站稳,重心居中;
- 手臂自然下垂或做简单手势,手势不要超出画布;
- 不要画跑动、悬空、大透视——配上位移动画会很假。

## 三、6 表情参考

| 动作 | 眉眼 | 嘴 | 姿态/记号 |
|---|---|---|---|
| `idle` | 平视,自然 | 轻微笑 | 手臂自然下垂,标准站姿(此图是其他 5 张的基底) |
| `talk` | 睁眼 | **张嘴说话**(椭圆/半圆) | 可单手抬起做手势,身体其余不变 |
| `happy` | 眯成弧线(^^) | 大张嘴笑 | 可比手势;腮红可选 |
| `angry` | 皱眉瞪眼 | 抿嘴/咧嘴 | 怒气符号(井字青筋)可选 |
| `sad` | 委屈垂眼 | 嘴角向下 | 可加泪滴,肩膀微塌(幅度要小,保持对齐) |
| `surprise` | 瞪圆眼 | 张口成 O | 汗滴/感叹号可选 |

漫画记号(怒气、汗滴、音符等)是廉价且高效的表情强化手段,鼓励使用;但记号也要画在画布内,不要出血。

## 四、制作路径

### 4.1 手绘(PS / Procreate / 优动漫)

1. 建 440×640 画布,先画 `idle` 定稿(身体 + 表情),这一步决定全部 6 张的质量;
2. 定稿后复制 5 份,每组只改脸部图层,身体图层保持原样不动;
3. 用参考线锁住头顶和脚底位置,导出前逐张检查头脚是否对齐(把 6 张叠成 25% 透明度对照);
4. 逐张导出 PNG(保留透明通道),按 1.1 命名。

### 4.2 AI 生成

难点是 6 张一致性,推荐"**1 张基准 + 局部重绘**"流程:

1. 先生成定稿站立图。提示词骨架(6 张共用,只换结尾表情词):

   ```
   chibi character, 2.5 head-tall, full body, standing straight,
   front view, arms at sides, flat colors, thick outline, cel shading,
   xiangsheng performer wearing traditional changshan, simple background,
   [表情词: gentle smile / talking open mouth / laughing happily /
    angry frowning / sad teary / surprised open mouth]
   ```

   两人通过固定角色描述词区分(如甲加 `purple changshan, tall thin`,乙加 `orange changshan, short round`),并**固定 seed**。
2. 生成纯色底再抠图,或直接生成透明底(视工具支持);抠图后统一缩放摆放到 440×640、脚底贴底边;
3. 后续 5 张用 img2img 低重绘幅度(0.2~0.35)或局部重绘(inpaint)只改表情区,身体不动;
4. AI 出图后手动修脸往往比纯生成更快,推荐混合流程。

#### 表情差分防身型漂移(整图重生成时)

整图重生成时每个像素都会被重新采样,"只改表情"只是软约束,体型/头身比会漂移(实测 sad 构图放大 1.2~1.3 倍、angry/surprise 身型走样)。控制手段按可靠度排序:

1. **局部重绘(inpaint)**:只对脸部涂蒙版,身体在蒙版外不可能变——最可靠;sad 等需改姿势的例外,需蒙全身重出;
2. **六格表情差分表**:一次生成 2×3 六格(平静/说话/开心/生气/沮丧/惊讶),格间天然一致,再切图;
3. **提示词约束**:用"差分"行话 + 逐项点名不变量 + 反向禁令。单张模板(服装/配件按角色替换,工具支持时锁同一 seed):

   > 生成参考图角色的【生气】表情差分。严格保持不变:体型体格、2.5头身比例、脸型、发型发色、眼镜、连帽外套与T恤、工装裤、运动鞋、背包与耳机、双手姿势、镜头景别与角度、构图与背景。只改变面部表情:皱眉、瞪眼、鼓腮、嘴角下压。角色与参考图必须100%同一人,不能变胖变瘦、不能变高变矮、不能改变年龄感。

   六格差分表模板:

   > 同一个Q版角色的六格表情差分表,2行×3列,每格全身:①平静 ②说话张嘴 ③开心大笑 ④生气鼓腮 ⑤沮丧含泪 ⑥惊讶瞪眼。六格中角色的体型、头身比、发型、服装、姿势、镜头距离与角度完全一致,只有面部五官表情不同;纯白背景,格子间留白,商业游戏角色设定稿质量。

已生成素材若只是大小偏差(构图被放大),`process_user_sprites.py` 的头部宽度归一会自动校正;体型形状层面的漂移只能重新生成。

### 4.3 约稿交接清单

直接把下面这段发给画师:

> 画两个 Q 版(2~2.5 头身)相声搭档角色的全身立绘,每个角色 6 张表情差分(站立/说话/开心/生气/沮丧/惊讶),身体完全一致只变脸部表情。440×640 px 画布,PNG 透明背景,全身脚底贴画布底边,头顶留 10~20px,不留影子。扁平大色块 + 粗描边风格,两位角色配色一冷一暖(建议蓝 #3d8bd4 与灰蓝 #5a6472),正面或微侧站立姿,6 张头脚位置严格对齐。文件名小写:idle / talk / happy / angry / sad / surprise。

## 五、常见错误对照

| 错误 | 后果 | 纠正 |
|---|---|---|
| 画了影子 | 角色底边对齐窗口,看起来悬空 | 不画影子;地面反光也不要 |
| 6 张头脚不对齐 | 交叉淡入时身体跳位、穿帮 | 用同一身体基底 + 参考线,导出前叠图检查 |
| 背景不透明(白底/纯色底) | 悬浮窗里出现一块色块 | 导出 RGBA 透明 PNG |
| 写实头身比 | 320px 下表情看不清 | 改 2~2.5 头身 |
| 文件名大写或拼写不符 | 程序找不到图,回退胶囊小人 | 严格用 `idle/talk/happy/angry/sad/surprise` 小写 |
| 角色只占画布下半 | 显示出来角色偏小 | 撑满画布高,脚贴底、头顶留 10~20px |
| 画了多余动作图(shake/jump) | 白画,程序不读取 | shake/jump 复用 idle,只需 6 张 |
| 分层交付(身体/衣服分开) | 程序无法合成,没有图层系统 | 服装画进整图,每动作一张完整 PNG |

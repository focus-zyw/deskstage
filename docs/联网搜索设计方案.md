# 聊天联网搜索设计方案

> 来源:Re-Dreaming_Angels_DesktopPet 调研——服务端 web_search(模型自主决定何时搜)
> + 联网使用规则注入。本方案把它移植到本项目的 actors 聊天链路与 llmGateway 网关。

## 目标与范围

- **做什么**:自由聊天(单聊面板 plain 直答 + 群聊 schema 协议)在开启后,模型可对
  时效性/事实类问题先检索再以角色口吻回答;检索由服务端执行,模型自主决定何时搜。
- **不做什么(v1)**:
  - 语音对话(流式通道 SSE 形态不同,且语音延迟预算紧,后续单独评估);
  - 演出/相声/翻译/事实提取/工具规划等非聊天调用(延迟与成本不必要);
  - 自定义模型档案与中转端点(host 判定不可靠,一律不注入工具,功能静默关闭);
  - 浏览器端爬虫/自建搜索(不引第三方搜索 API key,沿用厂商服务端检索)。

## 双厂商传输形态(请求层)

网关是唯一咽喉(`llmGateway.complete`),按端点 host 分流:

| 端点 | 传输 | 请求形态 | 响应解析 |
| --- | --- | --- | --- |
| `api.deepseek.com`(默认主模型) | Responses API | `{base}/responses`:`{model, instructions(=system), input(=其余消息), tools:[{type:'web_search'}], tool_choice:'auto', max_output_tokens:4096}`;不传 response_format | `output_text` 或 `output[].message.content[].output_text`,剥 `<think>` |
| `open.bigmodel.cn`(智谱) | chat/completions | 既有 body + `tools:[{type:'web_search', web_search:{enable:true}}]`,response_format 照旧 | 既有 choices 解析,零改动 |
| 其他 host | 不支持 | 工具不注入,行为与关闭时一致 | — |

要点(抄自对方实测教训):

- **DeepSeek 联网档 `max_output_tokens` 固定 4096**:搜索结果消耗输出预算,
  小预算会 `incomplete`(256 必截断、1024 仍可能截句尾);智谱走 chat/completions,
  检索结果进输入侧,`max_tokens` 抬底到 1024 防协议 JSON 被截即可。
- **路径假设**:Rust 端点代理按 `base + path` 解析且放行任意同主机路径,DeepSeek
  默认 base 含 `/v1`,故请求落到 `/v1/responses`(按 DeepSeek /v1 兼容惯例;
  若端点 404,该轮按普通失败呈现,关掉开关即恢复,不影响其他链路)。
- **400 自动降级**:带工具请求 400(厂商参数漂移/中转不认)时降级为无工具重试一次
  ——沿用"端点不支持 json 模式 400 降级"的既有先例,保证开关打开永不放大故障。
- **超时抬底**:adapter 层 40s → 联网档 75s(检索加数秒到十几秒)。

判定谓词单点收口:`webSearchTransportOf(baseUrl): 'zhipu-tools' | 'deepseek-responses' | null`,
提示词侧与请求侧共用,杜绝"提示说能搜、请求没带工具"的漂移。

## 提示词侧(联网使用规则行)

不做双版本人设文件(对方是人设为单字符串的权宜;本项目的 promptBuilder 组装式架构
只需一行规则)。规则行(静态常量)随 actorPrompt 注入 system(两种形态都带,同
协议块常驻语义):

> 联网搜索已开启(系统在需要时自动检索):遇到时效性问题(今天/最新/现在)、
> 不了解或超出角色世界观的事实类问题,先核实再以角色口吻自然回答;查不到就坦率
> 说不确定,绝不编造具体数据;不要提及"搜索/联网"等工具细节,不要罗列来源链接。

注入缝:`chainExtras`(openUserTurn 时按当轮配置算好)→ `prepareExtras` →
`PromptBuildInput.webLine` → actorPrompt。**门控条件与工具注入完全一致**:
`cfg.webSearch === true && 该角色绑定主模型档案 && transportOf(主端点) 非空`——
自定义档案的角色既不带工具也不会被承诺能搜。

## 配置与设置

- `AppConfig.webSearch: boolean`(默认 false);设置 → AI 模型 → 主模型卡片加开关
  「聊天联网搜索(实验)」。热生效:adapter 侧经 getter 每次调用读最新配置,
  提示词侧逐轮重算,无需重启。

## 诊断

- `llm_started` 增可选 `web: true`(注入工具的那次调用),回答"联网到底生效没有"。
- 降级重试经既有 llm_finished(status=400)可见,不另设事件。
